# 怎么分享这个项目

仓库地址：<https://github.com/wozhenshiliudada/kaggle-airline-satisfaction-s6e10>

## 直接分享

这是公开仓库。将上面的链接发给别人，对方即可查看代码和 Markdown 文档。

如果希望对方先了解我们的思路，直接分享方法总结：

<https://github.com/wozhenshiliudada/kaggle-airline-satisfaction-s6e10/blob/main/METHODS.md>

## 下载和复现

网页点击 **Code → Download ZIP** 可以下载代码。会用 Git 的人可以执行：

```bash
git clone https://github.com/wozhenshiliudada/kaggle-airline-satisfaction-s6e10.git
```

先按 README 运行 CPU 基线，再决定是否复现高级历史实验。源码下载不包含比赛数据、模型权重或历史预测缓存；比赛数据需对方自行通过 Kaggle 获取。

## 让别人提交修改

对方可以 Fork 仓库，在自己的副本修改后提交 Pull Request。

如果希望对方直接向你的仓库推送代码，在仓库的 **Settings → Collaborators → Add people** 输入其 GitHub 用户名并邀请。对方接受后即可协作。GitHub 协作权限和 Kaggle 比赛队伍是两套独立设置。

## 分享固定版本

仓库的 `main` 会随更新变化。需要引用固定版本时，可以分享某个 commit 的页面或文件链接；这样读者看到的是同一份代码。

官方操作说明：[下载源码](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)、[邀请协作者](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository)。
